My recommendation

Concept B — Bold Kinetic matches every signal you gave: bold/new, mobile-first, conversion-driven, and it reads young and continental. The dark canvas makes cut-out people and colour blocks pop, which directly serves the image-heavy home you want.

If you'd rather the site feel like a prestigious institution, go A — Gilded Continental. If you want warm and human, go C. Mixing is fine — tell me e.g. “B layout + A’s green/gold palette”.

The footer fix (all concepts)

The current footer ends in a giant “Afrovanguard” wordmark that swamps everything. New footer: tidy link columns + a compact brand lockup, a single newsletter/CTA line, legal row — no oversized wordmark.
