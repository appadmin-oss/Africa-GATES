# Requests: asking and deciding

Anyone who can’t do something themselves asks. Each request has one decider, a usual time, and a trail.

| Status | Means | Next |
|---|---|---|
| Waiting | With the decider | Approve, ask for info or decline |
| Needs info | The decider asked a question | The requester adds info, or withdraws |
| Approved | Done; the change is made | Read only |
| Declined | Not this time, with a reason | Ask again with the fix |
| Withdrawn | The requester stopped it | Read only |

> **Rule:** Asking for info and declining always need a note.

> **Tip:** A request waiting more than a day turns amber on the decider’s Home.
