# Running the door

Scanners hold an offline list, so the door works without signal. Red passes go to the gate lead, never back to the queue.

1. **Pair scanners the day before.** Event settings › Devices. Open /door on the phone and scan the code.
2. **Load the offline list.** Each scanner downloads every valid pass. Check ‘Offline list loaded’.
3. **Brief the stewards.** Scan every pass; never let someone in by eye. Count the queue every 30 minutes.
4. **Watch lost scans.** The target is 0. A lost scan means someone got in without a record.
5. **Unpair after.** Unpairing wipes the list from the phone.

> **Watch out:** A steward never decides a red pass. It goes to the gate lead, who can check the name and the payment.

> **Tip:** Volunteer hours at the door come from check-in and check-out scans. Nobody has to log them.
