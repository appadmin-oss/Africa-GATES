# Letters

Finalist, sponsor and reference letters merge from records and are signed by the named person.

- The finalist letter includes how voting works, from the edition’s own rules.
- Sponsor letters merge the tier and the benefits owed.
- Volunteer reference letters list only verified hours and roles.

> **Tip:** Preview with one real record before sending to all.
