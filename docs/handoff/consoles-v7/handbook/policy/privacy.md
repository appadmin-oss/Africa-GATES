# Privacy and data

Collect what a task needs, mask it on the server, and keep it only as long as the retention window.

- Phone numbers show as 0803 ••• ••12 to anyone who doesn’t need them.
- ID photos for door, money and data roles are deleted after the check.
- Anyone can download their data from their account.

> **Watch out:** Retention windows aren’t set yet, so erasure can’t run. This needs a decision in Settings › Legal.

> **Rule:** Masking happens on the server. Hiding data in the page isn’t masking.
