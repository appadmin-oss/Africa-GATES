# How the console is laid out

Every award edition, event and giving partner is a place with its own menu. You go in, work, and come back out.

The console has one menu at the top level and a separate menu for each thing you can open. Opening Teachers Prize, 4th Edition swaps the menu for that edition’s own pages: Overview, Nominations, Judging and so on. The name at the top of the menu is the switcher; Back brings you out.

## The five patterns

| You want to… | Use | Example |
|---|---|---|
| Go into a thing and stay a while | The menu (drill-in) | An edition, an event, a partner, Settings |
| See another one of the same kind | The switcher under Back | 4th Edition → 3rd Edition |
| See another view of the same thing | Tabs under the title | Review · Desk · Duplicates |
| Act on one record | A drawer from the right | A nomination, a payment, a request |
| Jump anywhere | Find, ⌘K | Type “refunds” or an old page name |

## Keys worth learning

- ⌘K opens Find. Enter opens the first match.
- ⌘J opens Ask, which answers from the place you’re in and this handbook.
- Alt [ and Alt ] switch to the previous or next edition or event without opening the switcher.
- Alt ↑ goes back. Esc closes any drawer.

> **Tip:** Switching keeps your page. If you’re on Judging in the 4th Edition and switch to the 3rd, you land on the 3rd Edition’s Judging. If that page doesn’t exist there yet, you land on Overview and a line tells you why.

## Counts and colours

A number beside a menu item is work waiting on a person. Red means it affects production right now; amber means it may. A menu item with nothing waiting shows no number at all, never a 0.
