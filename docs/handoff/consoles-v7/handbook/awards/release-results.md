# Releasing results

Results are sealed until one act releases them. Tie it to the ceremony cue so the page, emails and the hall screen change together.

1. **Check judging is closed.** Release is unavailable until every category has quorum.
2. **Preview.** See the results page as the public will. The overall winner comes first.
3. **Choose the moment.** Now, a time, or the ceremony cue in the event’s run of show.
4. **Release.** One act. The seal’s hash is recorded and verified on Data and audit › Integrity.

> **Watch out:** A release can’t be undone. A correction is a new, logged release with a reason shown publicly.

> **Tip:** Badges, certificates and the legacy vault entry are issued automatically at release.
