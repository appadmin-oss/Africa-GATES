# Judging: panels, conflicts and quorum

Panels score finalists on the edition’s rubric after voting closes. Conflicts exclude a judge from that category.

1. **Invite judges.** They sign in to the judges’ area, never the console.
2. **Collect conflict declarations.** A declared conflict excludes the judge from that category automatically.
3. **Open scorecards.** After voting closes. Each judge scores every finalist in their panel.
4. **Check quorum.** Each category needs at least 3 complete scorecards.
5. **Close judging.** Scores combine with votes using the edition’s weights.

> **Rule:** A rubric criterion that has been used is retired, never deleted.

> **Rule:** Volunteers never see scores or judges’ notes.
