# Audit of the build branch, 5 Oct 2026

Branch audited: `claude-finme-dues-training-fees` (the folder `Africa-GATES-claude-finme-dues-training-fees-l54o5j`). Read against this bundle. Each item gives the file, what's wrong and the fix. Fix in this order.

## P0: the public site does not render

1. **92 public page templates, 2 layouts and 27 partials were deleted** (`docs/handoff/DESTROYED.md`, 3 Oct). `templates/pages/` now holds only `dev-ui.twig` and `events/door.twig`. 80+ controller `render()` calls point at files that no longer exist (home, awards, vote, nominate, results, events, shop, account, help, blog, legacy, pulse…). Per DESTROYED.md, **66 public GET paths now return HTTP 500** and each one writes a `PublicFault`.
   - **Fix:** do not deploy this branch. Either restore the destroyed templates on a `legacy/` path and keep them routed until each phase ships its replacement (recommended), or rebuild Phases 2–9 before any deploy. A page is only deleted in the same commit that ships its rebuild.
2. **`pages/error.twig` is gone**, so every error falls through to a bare `<h1>500</h1>`. **Fix:** rebuild `error.twig` on `layout/shell.twig` first (no data dependencies).
3. **POST handlers that re-render a form on a validation error now 500** (nominations, register, sign-in, partner, stands). A visitor who mistypes an email loses the form. **Fix:** this goes with item 1.
4. **Legal and money surfaces deleted** (flagged "MUST RESTORE" in DESTROYED.md and still missing):
   - `ai-collection-notice.twig`: the NDPA point-of-collection notice. Required wherever free text is collected.
   - `cookie-notice.twig`: no consent banner renders. Build `CookieConsent.dc.html` on the `ag_privacy` model (Q11 below).
   - `footer.twig`: the only every-page link to refunds, vendor terms, support and the legal row.
   - `account-payout.twig`: two live POST routes, and money is owed.
   - `passkeys.js`: the only browser path into five live routes.
   - Also restore `flash.twig` and `field.twig` (form error ARIA).

## P1: chrome is present but broken

5. **`components/chrome.css` was destroyed**, so the site header, app bar, tab bar, Menu sheet and Quick settings render with base styles only. **Fix:** Phase 2 rebuilds `chrome.css` from `SiteHeader`, `AppBar`, `MobileMenu` and `DisplayReading` DCs.
6. **`header.js` and `site-search.twig` destroyed**: the header's Search button, Aa and language popovers, the toolbar's arrow keys and the basket badge do nothing, while their ARIA still claims they work. **Fix:** rebuild with Phase 2, or hide the buttons until then.
7. **Wrong breakpoint.** `site-header.twig` says it hides below **768px**; the spec is **600px** (`LAYOUT-BRANCHES.md` §1). With `chrome.css` gone, nothing hides anything, so both chrome sets render at every width. **Fix:** the rules in LAYOUT-BRANCHES §1 and §5, plus the breakpoint guard test.
8. **`main.css` carries 767/991/992/900/700/640 breakpoints.** It must not load on shell pages (it doesn't today; keep it that way, and delete it when the last legacy page is gone).
9. **Gee is missing on every shell page** (GAPS Q19 unanswered). **Fix:** yes. Mount `Gee` from `layout/shell.twig`'s `gee` block on every page except Pulse, with `--ag-bottom-ui` clearance.

Copy must say "adds to the tally".
11. **Waitlist hold** was 24h in the bundle; the code is 48h (`EventWaitlist::OFFER_HOURS`). **Fixed** to 48h in the HANDOFF and `EventsPage`.
12. **Account and Challenges** were built from DCs that weren't in the bundle. **Fixed:** `AccountPage`, `ChallengePage` and `ChallengeBanner` are now in `design/`.
13. **NominationFlow and NominateHub** in `design/` were older than the latest versions. **Synced.**
